# 🧘 Kinetic Pilates Blog

> **Ders 1 Projesi**: Modern, çift dilli (TR / EN) ve kinetik animasyonlara sahip dinamik Pilates blog sitesi.

---

## 🌟 Özellikler

- ⚡ **Next.js & React 19**: Turbopack destekli modern mimari.
- 🎨 **Kinetik Tasarım**: Akışkan geçişler, cam panel (glassmorphism) efektleri ve tek ana vurgu rengi (**Canlı Turuncu `#FF6B00`**).
- 🌐 **Çift Dilli Dinamik Yapı (Bilingual)**: Türkçe & İngilizce anında geçiş desteği.
- 📖 **Okuma Deneyimi**: Sayfa üstü okuma çubuğu, kategori filtreleme ve arama.
- ☁️ **Vercel & Domain**: Bulut sunucusu ve özel alan adı hazır.

---

## 🛠️ Yerel Geliştirme

```bash
# Bağımlılıkları yükleyin
npm install

# Geliştirme sunucusunu başlatın
npm run dev
```

Tarayıcınızda `http://localhost:3000` adresini açın.
